One object · 241 symbols · no second exemplar anywhere

One disc. No twin. No known reading.
This is the entire corpus.

The Phaistos Disc is a single fired-clay disc, stamped on both faces with 241 pictorial sign-impressions from 45 sign types — and no second object using the same script has ever been found anywhere on Earth. Our first goal is to establish what is actually known about the object itself. Our second is to work out what, if anything, could ever count as defensible evidence about its meaning given that constraint. Our third is to catalog the many decades of claimed readings and why none has held up. A translation may or may not follow — read on for what "started" actually means.

Why this is a harder starting line than any sibling project

There is no second text. There never will be.

Our sibling investigations of the Voynich manuscript and rongorongo each work from a corpus of many pages or many objects. The Phaistos Disc is one object. Standard decipherment methods lean on repetition and structure across many texts to tell a correct reading from a merely plausible one — with a single 241-symbol object, that check does not exist and cannot be built. This project treats that constraint as the central fact shaping everything else, not a footnote.

How the investigation works

These specialist functions approach the same single object from different directions — combined, added, or retired as the work needs, not a fixed cast. Git history makes every change reviewable. Read the full department charter ↗

01

Statistician

Sign frequency and positional analysis on the single object — and how little a sample this size can actually support.

02

Linguist

Tests whether the sign sequence's structure resembles a known script closely enough to support a partial reading.

03

Cryptanalyst

Examines the stamped-impression production technique and tests any proposed reading's own internal logic.

04

Historian

Authenticity, provenance, dating, and the full catalog of prior claimed readings and why each failed.

05

Skeptic

Holds "no reading is verifiable" as the default position and tests every claim against it.
