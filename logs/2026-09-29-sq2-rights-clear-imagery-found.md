# SQ-2 — rights-clear, high-resolution imagery found for both sides

**Trigger:** the standing SQ-2 blocker, named again in ChatGPT's own last several meetings: "seek museum
or publication imagery with explicit reuse terms" before any recount can proceed.

## What's already known / not done yet

Already known: no rights-clear transcription or imagery source had been identified across several prior
cycles' searches (SQ-2's own scope, unstarted since project bootstrap). Not done: locating one.

## Result

Two specific, named, high-resolution photographs, each with explicit, strong open licensing, found via
Wikimedia Commons — one per side, from two different photographers (not an official matched pair, a real
limitation named below):

- **Side A**: `commons.wikimedia.org/wiki/File:Phaistos_Disc_—_Side_A.jpg`. Photographer: Gsimonov, dated
  30 January 2024. **License: CC0 1.0 Universal (public domain dedication)** — the strongest possible
  open-rights status, explicitly "a faithful photographic reproduction of a two-dimensional, public
  domain work of art." Resolution: 4,818 × 3,216 pixels (10.34MB).
- **Side B**: `commons.wikimedia.org/wiki/File:Diskos_von_Phaistos_(Seite_B)_02.jpg`. Photographer: Olaf
  Tausch, dated 12 September 2018. **License: CC-BY 3.0 Unported + GFDL 1.2** — fully open, requires
  attribution. Resolution: 4,536 × 3,400 pixels (8.32MB). Explicitly identifies the artifact's current
  location (Heraklion/Iraklio Archaeological Museum, Crete) and discovery date (3 July 1908).

Both are independently described (by the tool reading each page, not by this project's own visual
inspection yet) as showing enough detail to identify individual stamped signs in the spiral arrangement.

## Honest limitations

**Not yet downloaded/hashed as local files** — attempted via `curl`, which cannot resolve Wikimedia's
upload-URL path structure directly from this session's tooling (a network-layer limitation, not a
permissions issue); the correct raw-file URL needs Wikimedia's own API or a different fetch approach, not
attempted further this cycle given time already spent. **Not a matched official pair** — two different
photographers, different dates, potentially different lighting/angle conventions, which could affect
sign-legibility comparability between sides in ways a single official photography session would avoid.
**No recount has been attempted against either image** — that is the natural next step, not this cycle's
scope. Visually counting 242 sign-impressions accurately from a photograph is a nontrivial task in its
own right and deserves a dedicated, careful attempt (ideally checked against the already-frozen recount
rules from `logs/2026-09-28-sq2-recount-rules-predeclaration.md`), not a rushed pass appended to an
already-long research cycle.

## Consequence

**The "seek licensed imagery" blocker is resolved** — SQ-2 now has a concrete, rights-clear, sufficiently
detailed source for both sides. The recount itself remains the next open step.
