# SQ-2 — predeclared damaged-sign and oblique-stroke handling rules, before any recount

**Trigger:** ChatGPT's Meeting 13 decision: "A recount must predeclare damaged-sign and oblique-stroke
treatment." Written before any recount is attempted, so the rules can't be shaped after seeing how they'd
affect the 241-vs-242 discrepancy already on file.

## What's already known

The only count data on file is Wikipedia-tier: 45 sign types, 242 total occurrences (123 side A + 119
side B), 61 words (31+30), and 18 oblique understrokes described as marking word endings and possibly
subdividing "paragraphs." No source yet on file states how damaged/ambiguous signs or the oblique strokes
were themselves counted or excluded to reach these figures — a real gap this predeclaration doesn't close,
but any future recount must state its own rule rather than silently inheriting an unstated one.

## Predeclared rules

**Damaged or ambiguous signs**: a sign impression counts toward the total **only if enough of its shape
survives to assign it to one of the 45 catalogued sign types** with the same confidence standard the
source catalog itself uses (per whatever named source is eventually pinned — Baldacci 2021 or the 2024
Oxford chapter, not yet primary-read by this project). A position that is visible but not confidently
assignable to a type is recorded as a **separate "unclassified" count**, never silently folded into either
the total or omitted without a note — mirroring the three-state uncertainty discipline the sibling
linear-a-collective project already established for SigLA (unreadable / unclassified / unsure-value), a
useful precedent even though the specific source differs.

**Oblique understrokes**: counted **separately from the 45-sign-type inventory**, not as their own sign
type and not folded into any individual sign's count — they mark a structural feature (word-ending,
possible paragraph division) rather than a phonetic/ideographic unit. A recount states the oblique-stroke
count independently (Wikipedia's tier already gives 18) and does not let it inflate or deflate the
sign-occurrence total in either direction.

**Word/segmentation boundaries**: the 61-word, 31/30-side-split count already on file is treated as
provisional pending its own primary-source verification — a recount of sign occurrences does not
automatically re-verify the word-boundary count, since these are two different countable objects (signs
vs. radial-divider-delimited groups) that should not be conflated into a single "recount" figure.

## What this does not do

No recount is performed here. No source's specific treatment of any of these cases has been checked yet —
this predeclaration exists so that when a recount *is* attempted (once a rights-clear source is pinned,
per SQ-2's still-open blocker), it can be checked against rules written before anyone knew what the count
would come out to.

## Honesty precommitment

If a future recount under these rules produces a number that disagrees with either the 241 or 242 figures
already on file, that result will be reported as-is, including if it disagrees with both.
