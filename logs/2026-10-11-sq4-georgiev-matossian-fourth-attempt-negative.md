# SQ-4 — a fourth attempt at Georgiev/Matossian criticism: still negative, one near-miss caught

## Precommitment self-review (written before searching)

**Known:** two of the catalog's ten rows (Georgiev 1976, Matossian/"Lozano" 2013) still lack
the named-reason-for-rejection layer SQ-4's scope requires. Prior cycles have repeatedly named
"search Kadmos/Minos for a Georgiev review" as the next step without actually attempting it
(the status notes record this intention at least twice without execution).

**Not done yet:** that specific targeted search has never actually been run; Matossian's paper
has also never had a citation/reception search attempted (only the full text itself, blocked by
403/404).

**Design and why it's non-circular:** run the specific, previously-only-intended search for a
Kadmos/Minos review of Georgiev's 1976 paper, and separately search for any citation/reception
of Matossian's 2013 paper. Report whatever is actually found, including if it's another
negative result — this catalog's own discipline treats a genuine disclosed negative as
informative, not as a cycle to be padded into a false positive.

**Honesty precommitment:** if a search result looks promising but doesn't independently verify
on a follow-up check, report the failed verification explicitly rather than keeping the
promising-looking first impression.

## Findings

**Georgiev**: ran the targeted search this cycle. A first search surfaced what looked like a
real lead — a Griffith Institute archive file citing "a *Kadmos* review by Herbert Ferguson
(1978)" in connection with Phaistos Disc materials. **Follow-up search shows this does not hold
up**: a second, more targeted search for "Ferguson 1978 Kadmos Phaistos" found no such 1978
publication at all — the actual Griffith archive record is correspondence **to/from** Herbert
Ferguson dated 1994 (three letters, January-April), not a 1978 journal article. The first
search's synthesis appears to have conflated a correspondent's name with an unrelated
publication date. **This is disclosed as a caught near-miss, not adopted as a finding** — no
Kadmos/Minos review of Georgiev's 1976 paper specifically has been located across four attempts
now (this cycle plus three prior ones).

**Matossian**: ran a citation/reception search (not attempted in any prior cycle, which only
tried the full-text route). No citing work, review, or critique of Matossian's 2013 paper was
found. Three tangentially related competing solar/calendar readings surfaced (Reczko 2009,
Ridderstad 2010, Revesz 2022) but none was shown to engage with or cite Matossian's paper
specifically — Revesz's own reference list, where visible, does not include her.

## Outcome

Both remaining catalog gaps stay open after a genuine, disclosed fourth/first attempt
respectively. This is a real negative result, not a non-attempt: the specific search that prior
cycles repeatedly named as "the next step" for Georgiev has now actually been run (and a
plausible-looking but false lead caught before it could be merged in as a fact), and a new
search angle for Matossian (citation/reception rather than full-text access) has also been
tried and come up empty.

## Decision

Neither row is updated with a named criticism — there genuinely isn't one found yet. Recording
this explicitly so a future cycle doesn't re-attempt the exact same two searches without a new
angle (e.g., a specific journal's table of contents for 1977-1979, or direct outreach to
Mediterranean Archaeology and Archaeometry's editorial office, which would need the user's
sign-off as outreach on the project's behalf).
